Git identity for your patches

Setup fills in missing identities in these two checkouts only. Existing identities and global Git settings stay unchanged.

Setup downloads both repositories and opens a terminal for system prompts. Keep it open until setup finishes. You need a good internet connection, and at least 40 GB of free space. Windows also needs MozillaBuild.

Setting up your environment

Follow any prompts in the setup terminal. Downloads can take a while. You can close this window and return later; setup continues in the terminal.

Connect Phabricator and Bugzilla

Add your API keys to work with reviews and bugs from the dashboard. You can skip this step and add keys to your settings later.

Phabricator

In settings, choose Conduit API Tokens and generate a token.

Bugzilla

Keys are stored in your local .tb.json settings file. They are not encrypted. Blank fields keep keys that are already saved.
